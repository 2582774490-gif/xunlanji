# 宗门生活与个人线索 v0.1

## 设计位置

《寻岚记》的主线不是由宗门派发的一串必做任务。岚潮与旧界是所有玩家共享的背景谜团；入哪一门、是否做散修、回应何种山门事务，则是玩家自己留下的社会经历。

宗门提供身份、传功、贡献与可能的门规后果，但不垄断主线、功法或区域访问。离宗、换宗、拒绝事务都不会造成主线失败。

## 当前可运行的宗门循环

1. 自由加入，身份从外门弟子开始。
2. 探索、副本结算与资源进献获得贡献；境界和贡献共同决定晋升。
3. 内门登记宗门功法，但不强制玩家切换主修。
4. 宗门会在自己关心的真实区域公开少量轮值事务。
5. 事务需要玩家已到达对应区域，并交回明确来源的材料；完成后有冷却，不能反复刷取。
6. 退出宗门保留个人经历；雾隐剑宗等门规严格的势力会记录通缉。

它们是对世界生态和势力运作的反馈，而不是平均撒在所有地图上的日常任务。正式联网后，事务的发布量、结报上限、宗门库存和跨玩家结果应由服务端权威控制。
