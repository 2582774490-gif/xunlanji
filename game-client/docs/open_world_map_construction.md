# 大型开放世界地图建设原则

## 关键澄清

`雾溪渡口` 不是云岚村全图，而是云岚村东侧的一块可游玩微区：它承担村外探索、水府入口、采集和少量 NPC 交互。任何单张概念底稿都只能定义一个微区的空间气氛与资产语言，不能替代大型开放世界。

## 世界层级

```text
寻岚大世界
├── 第一大区：云岚村与近郊（炼气）
│   ├── 云岚村主聚落
│   ├── 雾溪渡口（微区）
│   ├── 药草坡、旧矿道、风雨驿道等野外微区
│   ├── 宗门接引台与云市
│   └── 雾溪水府、废弃矿脉、引气洞府等副本入口
├── 第二大区：宗门边境与雾原（筑基 / 结丹）
│   ├── 多个宗门驻地、集市、雾潮野外区与遗府入口
│   └── 固定与动态副本群
└── 第三大区：险地山脉与古遗址（元婴 / 化神）
    ├── 高阶势力据点、险地、古战场和禁区
    └── 高阶副本群
```

## 技术与美术实施

1. **区块化而非一张巨图**：每个大区由许多可无缝衔接的微区组成；跨大区时短暂加载，微区内保持连续探索。
2. **模块化资产库**：地表、道路、河岸、桥、建筑、树、石、雾、摊位、宗门装饰分别制作，可反复组合；绝不依赖一张不可编辑的大背景。
3. **主题变体**：同一模块按季节、岚潮、昼夜、宗门影响生成颜色和装饰变体，减少重复感。
4. **玩法节点独立**：副本入口、资源刷新、NPC、宗门设施、随机机缘、传送点和 PVP 区域均是独立节点，不烘焙进背景图片。
5. **加载策略**：首发以“大区 → 子区域/微区”流式切换模拟大型世界；服务器完成后再将附近玩家、资源和事件同步进对应区块。

## 雾溪渡口在世界中的位置

- 面积定位：云岚村近郊的一个探索节点。
- 向西：连接云岚村主聚落与云市。
- 向南：连接药草坡、低阶灵植区和随机岚潮事件。
- 向北：连接旧矿道与废弃矿脉副本入口。
- 向东：通过水府石门进入雾溪水府副本。
- 后续作用：可随雨季、雾潮和宗门争端改变资源、NPC 和动态事件。
