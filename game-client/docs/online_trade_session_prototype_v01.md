# 《寻岚记》十人房双人托管交换 v0.1

## 已实现的开发闭环

在同一个本机十人房中，两名玩家可发起、接受或拒绝一笔交换。交换进入报价状态后，双方各自提交物品数量与灵石报价；服务端使用房间账本校验余额与物品数，双方都锁定报价后一次性完成扣除与转入。任一方可在锁定前取消。

- 房间名册和位置消息不包含背包、灵石或报价。
- 交换状态只发送给两名参与者，旁观者不会收到对局内容。
- 服务端在结算时再次校验双方账本，避免客户端在报价后直接修改本地数值。
- 首个 UI 入口位于“云市”，可在拟议报价中组合多种非装备物品与灵石，再提交、锁定或取消；实际允许的数量仍由服务端账本复核。

## 重要边界

这不是正式经济服务。当前服务器允许客户端在加入**本机开发房间**时一次性登记本地背包作为会话账本的起点；它没有账号认证、云端角色档案、跨会话持久化、审计、风控或生产部署。因此它只能验证“服务端托管报价与原子交换”的技术路径，不能作为上线交易系统或真实资产结算使用。

正式上线必须改为：账号登录签发角色身份 → 服务端读取持久化背包快照 → 交易锁定物品 → 审计、限价、手续费和风控 → 原子提交至数据库。届时客户端不得上传自己的起始背包。
