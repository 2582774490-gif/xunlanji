# 《寻岚记》非线性弱主线 v0.1

## 目标

《寻岚记》的主线不是“接任务、交任务、拯救世界”的单轨流程。它提供一个全世界都会逐步感到的谜团，帮助玩家理解岚息、区域与势力关系；探索、修炼、交易、宗门、炼丹和 PVP 都不被它取代。

玩家可以随时搁置这条线，继续采集、修行、交易、下副本、入宗或做散修。主线不会给战斗数值、不会锁死玩法，也不会因为没有推进而惩罚玩家。

## 共享世界谜团：岚潮回流

“岚”不是凭空替代灵气的一种蓝色能量。游戏中可被修士感知、引导和炼化的是 **岚息**：山势、水汽、地脉与生灵吐纳在特定地貌中长期交汇后形成的可观察余息。不同灵根与功法对它的利用不同，但岚息本身不是单一属性。

近期，岚息开始在不应聚集的地点回流，形成“岚潮”。雾溪、水府、旧商道、矿脉、古遗迹和远方海港出现了彼此并不相同、却能互相印证的异常。旧界边缘似乎在重新显影，但没有任何一派掌握完整答案。

这条主线只推进三次叙事认知：

1. **岚潮初闻**：第一次真实探索后，玩家知道异常存在。
2. **异地同痕**：从水路、商路、古遗址三类来源获得任意两类痕迹，明白这不是孤立副本事故。
3. **旧界回声**：三类痕迹都出现后，知道旧界边缘与岚潮有关；宗门、商会、散修、妖族的解释互相冲突。

以上都是“知道得更多”，而不是强制目标。每一阶段不发放属性、装备、经验或区域通行权。

当三类痕迹都被玩家亲自印证后，游历簿会提供三种**可反复改写的暂时判断**：守界（先保护受影响的地脉与聚落）、溯源（先追查旧界与异象来源）、观变（先记录资源、妖兽与人心的变化）。它们只改变下一批可见线索的角度和叙事语言；不绑定宗门、不锁技能、不给数值奖励，也不要求玩家完成任何任务。因此同一位水灵根角色可以选择守界，另一位同样的水灵根角色也可以选择溯源或观变。

首批已落在云岚外野的真实生态位置：选择守界后，旧商道会出现关注猎户与地脉的护脉巡修；选择溯源后，石芽高地会出现比对旧界坐标的寻碑客；选择观变后，云麓疏林会出现记录药材、妖兽足印与物价变化的记事人。三人都只是可错过的动态 NPC，不给任务清单、不替玩家导航，也不要求玩家采纳他们的立场。

与这类见证者交谈后，游历簿会保存一条“个人回响”：例如旧道护脉簿、反纹拓片或七日雾露簿。个人回响来自实际互动，不能靠重复对话刷取；即使玩家之后改为另一种判断，已亲历的证据仍会保留。

第二大区“雾潮边境”延续同一原则，但不会复制云岚外野的人物与地形：守界者会在旧关外遇到护送药农与凡人的避潮护路修；溯源者会在矿滩倒纹旁遇到量测旧器坐标的寻矿师；观变者会在药泽遇到同时记录水位、药性与兽迹的记潮人。三条线索分别扎根商路、矿滩与湿泽，表达的是同一岚潮在不同生计中的后果，而非三份换皮任务。

## 因人而异：命途起点

每个角色都有一个最先浮现的“命途起点”。创角时，玩家可从五种叙事视角中主动选择一种；它不改变灵根、体质、属性、功法、装备或宗门资格，只决定最早容易注意到哪类岚潮线索。未选择的旧存档会根据灵根、体质与第一次真实发现推定一个起点，以保持兼容。角色已留下真实观察后，起点不再能被菜单重写，避免抹去已经发生的个人经历。

| 命途 | 容易先察觉的地方 | 但仍可自由走向 |
|---|---|---|
| 听潮者 | 雾溪、水府、潮港 | 商路、遗府、宗门、炼器等所有内容 |
| 识草者 | 灵植、药性、湿地 | 战斗、交易、阵器等所有内容 |
| 观炉者 | 矿脉、地火、器纹 | 丹修、潮港、御灵等所有内容 |
| 逐风者 | 高地、断崖、风雷窗口 | 水府、商会、遗迹等所有内容 |
| 照见者 | 幻雾、器灵、妖灵与古物 | 全部区域与派系 |

## 支线不是任务海

支线以可重复交错的“线索网”呈现：

- **地势之书**：资源和随机机缘只在合理生态位出现。
- **行商之网**：价格、材料和航图引出交易、拍卖与商路传闻。
- **人间回音**：NPC 好感、散修、盗匪、宗门身份与离门后果形成关系网。
- **山门立场**：加入宗门后出现，但退出不会让主线失败。

只有玩家真实采集、观察、击退遭遇或完成副本时，游历簿才记录线索；打开地图、浏览菜单、靠近区域都不会凭空生成故事进度。

游历簿还会保留玩家主动织入世界的轻量经历：第一次认识一个 NPC、在云市寄售或购置、尝试炼丹、加入或离开宗门，都可以留下各自的“世界支线”记忆。同一条记忆不可反复刷取，不给属性或装备奖励，也不要求补齐；因此有人会留下商路和市集的痕迹，有人只留下丹火、散修关系或山门往来。

## 当前原型实现

`story_weave_catalog.gd` 定义共享阶段、命途起点与支线网。`GameState` 把命途、世界痕迹和暂缓状态写入本地存档，并由游历簿展示。

云岚外野已接入首批实体“个人回响点”：听潮者在雾溪浅岸发现潮痕浮灯，识草者在云麓疏林发现逆时草结，观炉者在石芽高地发现反纹石芽，逐风者在岚息丘陵发现回风残铃，照见者在旧商道发现无主影契。它们都位于与内容相符的地貌区块，玩家须亲自走到并互动；它们不会成为自动导航任务。

命途不会只在新手区出现一次。完成首个个人回响后，雾潮边境会继续依据角色的命途放置第二处独有观察：听潮者在雾渠辨认回潮石环，识草者在药湿地观察并生药脉，观炉者在矿滩测出余温器砂，逐风者在高地追到逆风符阶，照见者在外海滩脊看见潮镜残影。每处都在对应生态扇区中有独立坐标、独立文本、独立游历簿记录；它们可以错过、可以暂缓，不提供数值奖励，不会强迫角色选择宗门、阵营或战斗路线。

现在，云岚外野、雾潮边境与古脊岭的首批散修、巡修、劫修和领地妖物也能带出水路、商路或古遗三类见闻。例如采药散修只会在云麓疏林谈到逆流露痕，边关巡修只会在旧关谈到消失的车辙，守碑散修只会在古战场谈到封存的旧界坐标。每个来源在同一角色存档中只记录一次：反复对话、重进地图或刷同类遭遇不会重复产出故事进度或奖励。
