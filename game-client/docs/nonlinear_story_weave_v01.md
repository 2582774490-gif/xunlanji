# 《寻岚记》非线性弱主线 v0.1

## 目标

《寻岚记》的主线不是“接任务、交任务、拯救世界”的单轨流程。它提供一个全世界都会逐步感到的谜团，帮助玩家理解岚息、区域与势力关系；探索、修炼、交易、宗门、炼丹和 PVP 都不被它取代。

玩家可以随时搁置这条线，继续采集、修行、交易、下副本、入宗或做散修。主线不会给战斗数值、不会锁死玩法，也不会因为没有推进而惩罚玩家。

## 共享世界谜团：岚潮回流

“岚”不是凭空替代灵气的一种蓝色能量。游戏中可被修士感知、引导和炼化的是 **岚息**：山势、水汽、地脉与生灵吐纳在特定地貌中长期交汇后形成的可观察余息。不同灵根与功法对它的利用不同，但岚息本身不是单一属性。

近期，岚息开始在不应聚集的地点回流，形成“岚潮”。雾溪、水府、旧商道、矿脉、古遗迹和远方海港出现了彼此并不相同、却能互相印证的异常。旧界边缘似乎在重新显影，但没有任何一派掌握完整答案。

这条主线只推进三次叙事认知：

1. **岚潮初闻**：第一次真实探索后，玩家知道异常存在。
2. **异地同痕**：从水路、商路、古遗址三类来源获得任意两类痕迹，明白这不是孤立副本事故。
3. **旧界回声**：三类痕迹都出现后，知道旧界边缘与岚潮有关；宗门、商会、散修、妖族的解释互相冲突。

以上都是“知道得更多”，而不是强制目标。每一阶段不发放属性、装备、经验或区域通行权。

## 因人而异：命途起点

每个角色都有一个最先浮现的“命途起点”。它根据创角灵根、体质以及第一次真实发现确定，只影响提示优先级，不限制后续路线。

| 命途 | 容易先察觉的地方 | 但仍可自由走向 |
|---|---|---|
| 听潮者 | 雾溪、水府、潮港 | 商路、遗府、宗门、炼器等所有内容 |
| 识草者 | 灵植、药性、湿地 | 战斗、交易、阵器等所有内容 |
| 观炉者 | 矿脉、地火、器纹 | 丹修、潮港、御灵等所有内容 |
| 逐风者 | 高地、断崖、风雷窗口 | 水府、商会、遗迹等所有内容 |
| 照见者 | 幻雾、器灵、妖灵与古物 | 全部区域与派系 |

## 支线不是任务海

支线以可重复交错的“线索网”呈现：

- **地势之书**：资源和随机机缘只在合理生态位出现。
- **行商之网**：价格、材料和航图引出交易、拍卖与商路传闻。
- **人间回音**：NPC 好感、散修、盗匪、宗门身份与离门后果形成关系网。
- **山门立场**：加入宗门后出现，但退出不会让主线失败。

只有玩家真实采集、观察、击退遭遇或完成副本时，游历簿才记录线索；打开地图、浏览菜单、靠近区域都不会凭空生成故事进度。

## 当前原型实现

`story_weave_catalog.gd` 定义共享阶段、命途起点与支线网。`GameState` 把命途、世界痕迹和暂缓状态写入本地存档，并由游历簿展示。

云岚外野已接入首批实体“个人回响点”：听潮者在雾溪浅岸发现潮痕浮灯，识草者在云麓疏林发现逆时草结，观炉者在石芽高地发现反纹石芽，逐风者在岚息丘陵发现回风残铃，照见者在旧商道发现无主影契。它们都位于与内容相符的地貌区块，玩家须亲自走到并互动；它们不会成为自动导航任务。后续会把每条线索逐步接入具体 NPC 对话、区域事件、交易委托和副本分支。
