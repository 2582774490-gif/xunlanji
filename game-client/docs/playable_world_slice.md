# 雾溪渡口：首个可运行世界切片

这是用于验证游戏运行链路的微区，不代表正式开放世界的完整地图，也不代表最终的可换装角色数量。

## 当前可验证内容

- 进入“开放世界”后，可点击 `Playable World Test` 进入雾溪渡口。
- 使用方向键移动玩家男模板；现阶段有八方向静态朝向，以及经 GPT Image 生成并处理后的南向六帧行走循环。
- 靠近灵草按 `E`：获得“雾溪灵草”和少量修为。
- 靠近雾溪水府入口按 `E`：回到已有副本界面，验证“世界微区 → 副本入口”的状态切换。
- 在微区按 `J`：验证战斗输入已被接收；尚未指定任何武器，因此不会伪装为完成了武器攻击动画。
- 按 `H` 或 `Esc`：返回开放世界框架页。

## 刻意保留的扩展接口

角色动画控制器与角色脚本都不依赖固定姓名或固定装备。后续将用角色模板、脸型、发型、时装、武器、功法和法宝配置替换当前测试资源；每把正式武器仍须先完成独立武器卡、攻击帧、特效帧和判定时序。

## 下一批建设顺序

1. 补齐该角色的其余七方向行走帧，再做基础待机、受击和空手动作。
2. 按地图模块管线拆分雾溪渡口的地表、桥、栈道、建筑、树木、岩石、前景雾和碰撞。
3. 为第一把已确认的武器建立武器卡，再制作唯一对应的攻击和特效资产。
