# 参考视频分析与新 2D 制作方向

## 已确认的方向变化

- 开放世界与副本统一为同一套 2D 斜俯视/俯视地图画风。
- 取消“副本内横版战斗角色与场景”的视觉路线。
- 副本仍保留实时手操、移动、普攻与五技能槽；区别只在场景规则、怪物、机关、镜头边界和奖励。
- 成品需是原创精致国风修仙 2D 资产，借鉴的是生产方式，不复制视频里的日式街景、像素素材、界面或布局。

## 视频一：场景素材拆分与摆放

可见内容包括完整场景示例、浏览器中的“提取图内物件/场景”步骤、去背景界面，以及 Godot 中大量拆分后的精灵资源和手工摆放结果。

可借鉴流程：

1. 使用完整背景概念图确定建筑、道路、植被、道具的整体气氛。
2. 将建筑、树、石、灯、桥等逐个拆成独立资产，而不是把整张背景固定死。
3. 对独立资产去除纯色背景，修正半透明边缘，导出透明 PNG。
4. 在 Godot 中以可排序精灵、TileMap 和独立碰撞区重建场景。
5. 手工调整遮挡、道路、资源点、NPC 点位和可行走区域，使游戏逻辑不受背景图限制。

## 视频二：基础地图生成后再编辑

可见内容包括 Godot 地图编辑模式、以背景图片生成基础地图、草地/石路等图块摆放，以及在生成结果上进行人工修改。

可借鉴流程：

1. 先制作一张只表达氛围与布局的“地图底稿”。
2. 从底稿提取地表、道路、边缘、植被和建筑模块，制作图块集。
3. 在 Godot 的 TileMap/场景中手工组装最终地图。
4. 生成图只作为底稿；碰撞、资源刷新、NPC、传送点、事件和副本入口必须是独立节点。

## 《寻岚记》采用的地图层级

1. `Ground`：草地、泥地、石板、水面等可平铺地表。
2. `Road`：道路、桥、台阶、河岸边缘。
3. `ArchitectureBack`：建筑后墙、远山、亭台的后层。
4. `Props`：树、石、灯、摊位、药草、可采集资源。
5. `Actors`：玩家、NPC、怪物、法宝投射物；按 Y 坐标排序遮挡。
6. `ArchitectureFront`：屋檐、树冠、近景雾气，用于前景遮挡。
7. `Gameplay`：碰撞、多边形区域、交互、资源刷新、传送、副本入口。
8. `UI`：虚拟摇杆、普攻、五技能槽、任务和提示。

## 第一张要生产的地图资产

云岚村东侧“雾溪渡口”概念底稿：雨后浅雾、溪流、石桥、木栈道、药草坡、村口小亭与远处水府入口。它将作为开放世界与雾溪水府入口共用的视觉基准；生成后再拆分为地表、道路、建筑、植被、前景和玩法节点。
