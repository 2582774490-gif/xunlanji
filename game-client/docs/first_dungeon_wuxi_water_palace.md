# 云岚村首个副本：雾溪水府

## 定位

- 类型：炼气期固定副本，横版 2D 即时手操。
- 入口：云岚村东侧雾溪渡口；雨后或岚潮升起时水府入口更清晰。
- 作用：教会玩家移动、普攻、五技能槽、闪避、机关、随机机缘与首个法宝奖励。
- 推荐人数：单人可进入；未来支持最多两人协作，不强制组队。

## 原创背景

雾溪旧河道曾是村民引水之处。百年前，一位无名水修为疏通山洪在此留下一座小型水府；后来岚潮改变水脉，水府被淤泥和雾气掩埋。如今水府守卫因灵脉失衡苏醒，并非纯粹邪物。玩家可以直接击败守卫，也可收集三枚“澄水石”修复水脉，获得额外探索奖励。

## 横版流程

1. **雾溪入口**：教学移动、跳跃与普攻；敌人是雾沼小妖。
2. **断桥回廊**：教学闪避、落点与岚潮雾障；随机出现灵泉露或残碑拓片。
3. **引水机括室**：教学互动；击败两只水甲傀儡或修复三枚澄水石开启闸门。
4. **水府主殿**：首领“水府守卫”；两阶段为水刃投射与回潮冲击，均须保持动作可读性。
5. **结算**：固定奖励纳灵玉佩、灵石与修为；随机奖励雾溪草、灵泉露或古旧水纹残片。

## 美术与制作拆分

- 背景：远云、远山、河谷、府墙、地面、近景雾草共六层。
- 敌人：雾沼小妖、水甲傀儡、水府守卫，均需独立横版动作包。
- 机关：断桥、闸门、澄水石、引水轮，均与碰撞区、交互区分离。
- 武器：首副本不预设任何武器特效；玩家仅在装备具体武器后挂接对应动作与特效。
