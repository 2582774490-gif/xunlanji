# 《寻岚记》参考视频：风格与制作标准 v0.1

## 结论

参考视频提供的是一套 **2D ARPG 的制作方法**，不是要复制它的像素素材或世界设定。

《寻岚记》采用相同的可玩性结构：斜俯视大地图、镜头跟随、八方向移动、独立武器跟随、帧序列攻击、独立特效、地图分层拼接与可交互地标；视觉替换为原创、精致、中国修仙题材的 2D 国风画面。修炼体系、宗门、人物、法宝、剧情与地图内容均为《寻岚记》原创。

## 从视频中确定的制作规则

### 1. 地图不是一张完整大图

地图由可重复使用的区块拼接而成，区块至少分为：

1. 地表底图：草地、山石、道路、水面。
2. 环境装饰：花草、树、灯、石碑、屋舍、桥、船、雾气。
3. 碰撞层：山体、房屋、水域、悬崖等不可通行区域。
4. 前景遮挡层：树冠、屋檐、崖壁、浓雾，角色经过时能正确遮挡。
5. 交互层：NPC、资源、传送点、副本入口、随机机缘锚点。

大世界通过 256 或 512 像素的地图区块组合扩展；每个大区有自己的地表调色、建筑包、资源包和副本入口包。这样地图能持续扩建，而不是重新画一张巨图。

### 2. 角色、武器、特效必须拆开

角色本体、时装、武器、法宝、攻击特效不可烘焙成同一张图片。角色节点应包含：

```text
Player
├─ BodySprite        # 性别、脸型、发型、时装
├─ WeaponPivot       # 武器挂点与方向偏移
│  └─ WeaponSprite   # 每种武器独立序列帧
├─ ArtifactLayer     # 可装卸法宝
├─ EffectLayer       # 技能、命中、受击特效
└─ ShadowLayer       # 地面阴影
```

这样同一个角色才能换时装、换法宝、换武器，并保证每把武器都拥有独立攻击动作和特效。

### 3. 八方向是完整动作系统，不是八张站立图

每一套角色动作都按八方向制作：南、东南、东、东北、北、西北、西、西南。首版动作包最低包括：

- 待机：每方向 4 帧；
- 行走：每方向 6 帧；
- 普攻：每方向 6–8 帧；
- 受击、翻滚、交互、施法：每方向按动作特性配置；
- 武器动作与对应特效：按武器单独生产，不默认共用。

当前的南向步行和攻击只属于技术验证，不能被称为完成的角色动作包。

### 4. AI 出图后的正确流程

1. 先建立角色/武器/场景资产卡，锁定身份、比例、配色、挂点和帧数。
2. 生成同一角色的“规范图”，再分批生成单动作、单方向的帧表。
3. 以纯色背景生成，抠图后统一脚底基线、画布尺寸和命名。
4. 切帧、检查重影/缺肢/比例漂移，再导入 Godot 动画资源。
5. 武器和特效独立生成、独立抠图、独立挂到锚点。
6. 场景背景同样拆为底图、建筑、遮挡和交互锚点；不得把不可拆分的 AI 整图直接当开放世界地图。

## 对当前原型的修正

现有三大区、镜头、区域门、资源点、NPC 点和副本入口保留为逻辑骨架；程序绘制的地表、道路、房屋只用于验证地图尺度，不是最终画风。

下一批正式资产优先做“云岚村地图包”，而不是继续零散生成角色图：

1. 草地/山路/水面底图区块；
2. 云岚村建筑包；
3. 树、石、草、桥、码头等前景和遮挡包；
4. 雾溪水府入口包；
5. 与其匹配的碰撞与排序配置；
6. 第一位玩家角色的完整八方向基础动作包。

## 不复制的边界

不复制参考视频中的具体角色、武器、像素素材、地图布局、特效形状或 UI。借鉴的是“模块化地图 + 分层角色 + 八方向帧动画 + 独立武器特效”的工程方法。
