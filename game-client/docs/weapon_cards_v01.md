## 每把武器的后续交付顺序

1. 武器卡：名称、品级、材料、主属性、技能定位、可交易规则。
2. 立绘/装备图：独立武器设定图和正侧细节。
3. 统一 2D 斜俯视动作：待机、八方向移动、普攻各段、技能、受击、收招。
4. 特效：每一个动作单独绑定，不能把剑气、火焰等泛化给其他武器。
5. 验收：可读性、碰撞范围、帧数、性能、与男女模板的握持关系。
