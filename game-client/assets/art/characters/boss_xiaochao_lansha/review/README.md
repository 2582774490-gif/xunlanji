# 绡潮妖姬·澜纱：首张资产锚点

本文件夹保存《寻岚记》雾溪水府首领的第一张可复用身份锚点图。

- `source_magic2/`：保留生成时的洋红抠图底稿，便于追溯和重做。
- `processed_alpha/`：已去除洋红背景的总图。
- `slices/`：正面、左侧、背面、右侧的透明 PNG；用于后续角色卡、立绘校对和动作资产对照。
- `manifests/`：程序与美术协作所用的资产清单。

本版本已经完成生成、去背和四视图切分；尚未作为游戏内移动或攻击帧使用。下一步应在确认人物审美后，以本图锁定的脸部、发型、服装和配色为基准，依次生成：静态立绘、斜俯视 2D 游戏本体、待机/行走/受击/技能帧表，以及水系技能特效。
