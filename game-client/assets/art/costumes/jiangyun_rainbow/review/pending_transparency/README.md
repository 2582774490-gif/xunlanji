# 绛云霓裳待透明复核候选

`jiangyun_rainbow_idle_north_west_v01_*` 是西北方向的生成候选。

该方向的人物、服装和朝向可作为后续生产参考，但广袖与发梢含半透明材质；当前基于色键的抠图仍可见少量绿色边缘。它**不得**进入 `GameCatalog` 的运行候选，也不得接入地图角色层。

要进入运行候选，需重新生成可拆分的实色边缘版本，或在获得原生透明输出条件后重新处理，并通过深浅两种背景的边缘检查。

`jiangyun_rainbow_idle_north_east_v01_*` 与 `jiangyun_rainbow_idle_north_east_v02_*` 是北东方向的两次生成候选：

- v01 使用绿色色键；白纱和发丝吸入绿色，抠图后出现绿边。
- v02 使用洋红色键；避开绿色后仍在半透明广袖留下洋红颗粒。`v02_edgecheck` 的一像素收缩不能在不损失袖缘的前提下消除该问题。

两组北东候选都只保留作构图、朝向与服装一致性参考，**不得**写入时装档案、地图角色层或任何角色动画图集。
