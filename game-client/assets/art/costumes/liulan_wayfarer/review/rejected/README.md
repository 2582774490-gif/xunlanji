## 合格项

- 服装配色、纹样、发冠、披帛与概念图一致；
- 洋红底可用于后续抠图测试；
- 八格排版与角色主体尺寸接近统一。

## 不合格项

- 8 个方向没有全部独立覆盖：存在重复或过于接近的背向/侧向姿态；
- 东南、西北等斜向没有达到可明确映射的八方向要求；
- 脚点和披帛外沿尚未完全统一，不能直接切片到当前角色的同骨架格子；
- 只有静态待机关键姿，没有行走、攻击和武器遮挡帧。

## 处理结论

该图仅保留为提示词与质量验收的反例，不会进入 `processed_alpha`、不会写入时装 `runtime_asset`、不会显示在地图或副本人物上。
