# 《寻岚记》Godot 客户端原型

这是《寻岚记》的首发客户端框架。它用于验证玩法结构、界面流转和内容数据，不是已完成的微信发布版或真实联网 MMORPG。

## 已经可以体验的框架

- 创建角色：男女模板、脸型模板、发型模板、首批角色立绘，以及不影响数值的命途起点选择。
- 修士洞府：作为所有游戏板块的总入口。
- 三大区开放世界：云岚村与近郊、宗门边境与雾原、险地山脉与古遗址。
- 固定副本与随机机缘：副本可进入本地战斗演示；机缘会掉落物品和修为。
- 修炼：炼气、筑基、结丹、元婴、化神，首发上限化神圆满。
- 行囊：首批 24 种武器大类、材料、法宝的逻辑入口；武器可接入独立动作与特效包。
- 宗门：自由加入/退出、外门身份、贡献晋升、区域轮值事务与门规后果。
- 市集：本地购买演示，及本机十人房中的双人托管交换开发原型。
- 1v1 论剑：本地武器动作验证，及本机十人房中的服务器裁定联机论剑原型。
- 图鉴与设置：NPC、内容分类和开发状态说明。

## 目录说明

- `src/core/game_state.gd`：跨页面角色状态、修为、背包、宗门和通知。
- `src/data/game_catalog.gd`：首发世界、境界、副本、武器、宗门、NPC、机缘与市集数据。
- `src/combat/combat_state.gd`：副本与本地 1v1 共用的基础即时战斗状态。
- `src/combat/online_duel_arena.gd`：联机论剑场；客户端仅提交移动与招式输入。
- `src/ui/main.gd`：完整导航和各系统的本地交互界面。
- `assets/art/prototype_batch_01/`：第一批角色立绘、地图方向图；其中横版动作试片已废止，不进入新管线。

## 运行方式

最简单的 Windows 试玩方式是双击项目根目录的 `启动寻岚记.cmd`：它会启动本机十人房开发服务器，并直接以 Godot 运行当前游戏；关闭游戏后，由启动器启动的本机服务器也会退出。

也可以使用 Godot 4.7 打开本目录中的 `project.godot`，然后运行主场景。副本内可点击按钮操作，也可使用 `J` 普攻、数字 `1` 至 `5` 释放技能。联机论剑需要先在 `server/` 启动本机十人房，再由两名玩家进入同一房间、发起并接受挑战。

项目已包含 Windows Desktop 导出预设 `export_presets.cfg`。导出前需要在 Godot 的“管理导出模板”中安装与编辑器一致的 **4.7.1.stable** Windows 导出模板；模板安装后，可从 Godot 的“项目 → 导出 → Windows Desktop”导出 `build/XunLanJi.exe`。当前仓库不提交导出产物，避免把大型二进制文件混入源码。
