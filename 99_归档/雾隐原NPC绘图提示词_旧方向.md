# 《寻岚记》雾隐原首批 NPC 绘图提示词 v0.1

## 使用方式

1. 每位 NPC 先复制“通用四视图提示词”，再接上该角色的“四视图角色段”。
2. 选定最合适的一张四视图作为角色锚点图，重新上传为图像 1。
3. 复制“通用面部提示词”，再接上同角色的“面部锚点段”。
4. 图片中不要写角色名、身份、编号或任何文字。

## 通用四视图提示词

```text
用途：游戏角色制作资产，四视图角色设定稿。
画风：原创高品质中国 3D 修仙动画角色建模设定，写实而风格化的中国面孔，自然人体比例，精细皮肤、发丝、布料、金属与皮革材质；低饱和青黛、雾白、岩墨配色，克制电影级柔光，清晰轮廓，服装结构真实可拆分，适合后续 2D 战斗角色制作。不要模仿任何现有动画、角色、服装、纹样或镜头。
构图：一张横向角色转面设定图，严格分成四个等宽竖向区域，从左到右依次为正面、左侧面、背面、右侧面；每个区域都是同一个角色、同一套服装、同一年龄和体型，完整全身、自然直立、双手放松、脚部完整可见、正交视图、无透视夸张。
背景：纯净暖灰白设计稿背景，无场景、无地面、无投影、无渐变。
约束：四个视图必须保持同一张脸、同一发型、同一服装结构、同一色彩；不要文字、标签、边框、额外人物、logo、水印、现代服装、夸张铠甲或武侠海报姿势。
```

## 通用面部细节提示词

```text
输入图像：图像 1 是该角色已确认的四视图锚点图。
用途：游戏角色制作资产，面部细节设定稿。
请求：仅基于图像 1 的同一角色，制作一张横向面部细节图，分成四个等宽区域：正脸中性表情、左侧脸中性表情、右侧 3/4 脸符合角色气质的轻微表情、眼睛与眉形及关键发饰/面部特征的局部特写。不得重新设计角色。
画风：与图像 1 完全一致的原创高品质中国 3D 修仙动画角色建模设定，写实而风格化的五官，自然皮肤、发丝和细微布料材质；不要模仿任何现有动画的具体角色设计。
背景：纯净暖灰白设计稿背景，无场景、无投影、无文字。
约束：只出现同一角色；四个区域的脸必须一致；不要美颜滤镜、现代妆容、身体全景、logo 或水印。
```
