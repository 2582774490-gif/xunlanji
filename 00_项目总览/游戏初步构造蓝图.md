# 《寻岚记》游戏初步构造蓝图

> 状态：v0.1（待制作意图确认）  
> 更新时间：2026-08-01

## 已确认的制作意图

- 游戏类型：有精美国漫立绘的 2D 修仙 RPG；开放地图探索、自由成长和可解释的随机机缘是核心。
- 世界体验：玩家能探索地图、加入或退出宗门、获取法宝与资源，并因选择产生不同的人生轨迹。
- 副本：从开放世界进入副本时，切换为横版 2D 动作战斗。
- PVP：首发只做 1v1、最多两名玩家同时对战。
- 角色：玩家从不同人物模板出发，通过时装、法宝与外观部件形成差异化造型。
- 美术：同一角色必须分别拥有国漫立绘、开放地图角色、横版战斗角色三套一致资产。
- 叙事：主线只承担世界和修炼体系的轻量引导，后续内容主要由探索、机缘、宗门与副本扩展。

## 核心循环

```text
开放地图探索
  → 采集 / 对话 / 触发机缘 / 宗门委托
  → 获得资源、线索、法宝或副本入口
  → 横版副本战斗与结算
  → 修炼、炼制、交易、外观与宗门声望成长
  → 进入更高风险区域，发现新的机缘与副本
```

## 四个首发玩法层

| 层级 | 玩家在做什么 | 首发边界 |
|---|---|---|
| 开放世界 | 在区域中移动、采集、交互、发现事件 | 先做一张可完整循环的地图：雾隐原 |
| 修炼与装备 | 境界、功法、法宝、时装和资源选择 | 先验证一条低境界成长线，不提前堆满全境界 |
| 副本战斗 | 进入横版关卡、操作闪避、普攻、技能与法宝 | 先做一座固定副本和一种动态机缘副本 |
| 社交与对战 | 宗门、交易、拍卖、1v1 切磋 | 先做安全规则明确的 1v1 擂台，不做多人混战 |

## 角色与资产规则

每个可用角色模板都要有一份“角色资产卡”，其资产不可互相替代：

1. **国漫立绘**：用于角色详情、剧情、卡片和展示；负责魅力与人物气质。
2. **开放地图角色**：用于世界中移动与交互；应拥有完整方向和移动状态。
3. **横版战斗角色**：用于副本与 1v1；先验收人物本体，再按武器卡分别制作动作与特效。
4. **时装与法宝**：以可替换部件或独立挂点管理；法宝/武器的攻击动作与特效不能预先绑定到人物本体。

## 第一条可玩垂直切片

目标不是制作完整 MMORPG，而是做出能判断“这是不是《寻岚记》”的第一段体验：

- 一名可创建并自定义外观的玩家角色。
- 雾隐原开放地图：移动、NPC 交互、采集点、固定资源点和一次随机机缘。
- 一个固定副本：进入后切换横版 2D 战斗，含探索、战斗、结算和掉落。
- 一个动态机缘副本：由地图环境条件触发，采用有限变体，而非纯随机拼接。
- 一种正式武器：先完成武器卡，再制作该武器的完整普攻、技能和特效。
- 一个 1v1 擂台：只验证匹配/邀请、同境界规则、胜负结算和基础观战边界。
- 一个宗门入口：加入、外门身份、门规提示和一项委托。

## 推荐的制作顺序

1. 确认下面的关键制作意图。
2. 为首位“玩家角色模板”完成三层人物本体试片并验收。
3. 建立第一把正式武器卡，再生成其动作与特效提示词。
4. 产出雾隐原的地图、NPC、资源和副本资产清单。
5. 用 Cocos Creator + TypeScript 建立可移动地图、场景切换和横版战斗原型。
6. 接入最小服务端能力：账号、角色存档、物品归属与 1v1 对战结算。
