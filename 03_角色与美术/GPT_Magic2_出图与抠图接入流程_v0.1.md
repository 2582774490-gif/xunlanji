# GPT Magic 2 出图与抠图接入流程 v0.1

## 适用范围

本流程是《寻岚记》后续角色、NPC、怪物、武器、法宝、丹药、宝药、图标、地图模块和特效的指定图像生产流程。使用 GPT Magic 2 生成；如果该出图端由主创登录或打开，Codex 只在已授权范围内填写提示词、保存产物和进行后续整理。

## 强制顺序

1. **先建卡**：先完成资产卡，冻结 ID、用途、尺寸、视角、状态、品质、世界来源和验收标准。
2. **单张试出**：一次只生成该资产的一张关键锚点图，例如角色四视图、武器设定图或怪物战斗本体图。
3. **主创验收**：由主创确认风格、身份、服装/材质、清晰度和玩法适配后，才能进入下一张。
4. **抠图去底**：保留原图；生成透明背景 PNG；检查发丝、水袖、半透明特效、边缘残色和阴影是否干净。
5. **切片分层**：按 Godot 所需切为帧表、图标、立绘层、背景层、碰撞参考层或特效层；源图不覆盖。
6. **引擎接入**：建立资源清单、命名、尺寸、锚点、动画帧率和碰撞/判定；在 Godot 中实际运行检查。
7. **版本归档**：记录提示词、输入锚点图、原图、透明图、切片图、验收结论和废弃原因。

## 目录约定

每个资产目录包含：

```text
source_magic2/       # GPT Magic 2 原图，不改写
processed_alpha/     # 去底透明 PNG
slices/              # 帧表、图标、分层素材
manifests/           # 尺寸、格数、锚点、来源、提示词 ID
review/              # 主创验收记录
```

## 抠图标准

- 不使用带场景、文字、水印或复杂阴影的图作为战斗角色源图。
- 透明边缘以 200% 放大检查；禁止洋红边、白边、锯齿、误删发丝、误删半透明水雾。
- 角色与特效分开抠图；武器与人物分开或保留可替换层，避免未来时装/换武器时重做整张角色。
- 地图背景优先按远景、地表、建筑、遮挡前景、雾效、交互物和碰撞层拆分；不直接把一张概念图当作无限大世界地图。

## 绝对禁止

- 未建资产卡即批量生成；
- 未经主创验收就继续生成同资产的动画、武器或特效；
- 覆盖原始出图；
- 使用现有作品的具体角色、服装、镜头、图标或特效作为复制目标；
- 把概念立绘直接当作可移动角色或战斗帧。
