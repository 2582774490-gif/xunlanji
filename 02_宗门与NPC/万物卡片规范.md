# 《寻岚记》万物卡片规范 v0.1

> 适用对象：NPC、世界宗门、玩家仙盟、法宝、妖怪、灵兽、资源、材料、地点、固定副本、动态副本、功法、任务事件。卡片是制作与版本管理资产，不是只写在游戏里的图鉴介绍。

## 两层卡片

| 层级 | 使用者 | 内容 | 原则 |
|---|---|---|---|
| 制作资产卡 | 策划、美术、动画、程序、测试 | 完整身份、玩法、数据、关系、视觉、提示词、版本与验收 | 每个可命名资产必须有一张 |
| 玩家图鉴卡 | 玩家 | 名称、剪影/主图、短传、发现地、基础用途、解锁状态 | 只展示玩家已知信息 |

本轮先制作“制作资产卡”；玩家图鉴卡从其中安全裁剪生成。

## 全部制作资产卡的固定区块

```text
卡片 ID / 类型 / 版本 / 状态 / 负责人
名称（工作名）/ 一句话定位 / 所属地图与势力
世界定位与来源 / 玩法功能 / 关联资产与事件
外观描述 / 视觉资产清单 / GPT Image 提示词 ID
数据字段 / 服务端状态 / 验收标准 / 变更记录
```

状态只允许：`概念`、`待出图`、`出图待审`、`已定稿`、`可制作`、`已上线`、`废弃`。生成出图不等于角色设计定稿。

| 世界宗门 | 门规、驻地、身份阶梯、运行状态、NPC 权威、入/退门规则、资源权限、敌友关系、制服/标志 |

| 妖怪/灵兽 | 种属、栖息环境、境界带、行为、攻击/掉落、环境关系、幼体/成体差异、四视图与材质细节 |
| 资源/材料 | 来源环境、刷新条件、采集工具、用途、绑定/交易规则、稀有度、图标、世界模型、采集状态图 |

## 命名 NPC 的最低视觉资产包

| 资产 | 用途 | 状态要求 |
|---|---|---|
| 四视图 | 正、左、背、右全身一致设计 | 概念通过后必备 |
| 面部细节图 | 正脸、侧脸、3/4 脸、眼眉/发际特写 | 概念通过后必备 |
| 主立绘 | 图鉴、对话、宣传 | 角色定稿后制作 |
| 战斗小人 | 2D 骨骼/序列帧基础 | 客户端制作前必备 |
| 动作表 | 待机、行走、受击、交互、技能/特殊动作 | 动画阶段必备 |
| 表情表 | 中性、喜、怒、悲、警惕 | 对话系统阶段必备 |

四视图和面部图用于锁定角色身份，不能直接当游戏战斗素材。选定一张四视图作为“角色锚点图”；之后的立绘、表情和动作图都需以它为图像参考生成或绘制。

### 视觉基准：高品质中国 3D 修仙动画

角色卡的视觉目标是“高品质中国 3D 修仙动画中的写实人物建模感”，重点提取：自然成年比例、骨相清晰但不真人写生化的五官、具有细微织纹的多层传统服装、低饱和但有材质层次的青黛/雾白/岩墨配色、克制的电影级柔光、干净而能用于 2D 战斗拆分的轮廓。

这是一套原创视觉方向，**不复制《凡人修仙传》或任何既有动画的具体角色、服饰、镜头、标志、纹样或场景构图。** 每个角色必须由自身身份、地区和关系决定服装与面孔。

## GPT Image 出图顺序

1. 用角色四视图提示词生成 2–4 个候选，选出最合适的角色锚点图。
2. 将锚点图重新上传，使用同编号面部细节提示词。
3. 四视图和面部通过后，二者共同作为主立绘、表情或动作参考的输入图像。
4. 美术统一比例、服饰层、发型、武器与颜色后，才可标为“已定稿”。

禁止在没有锚点图时直接生成“同一角色的下一张图”；这会造成脸、服饰和比例漂移。

## 提示词通用骨架

### 四视图

```text
用途：游戏角色制作资产，四视图角色设定稿。
主体：<角色身份、年龄、性别表现、体型、气质>。
服装与道具：<服装层次、材料、主色、配件、武器/工具>。
画风：原创高品质中国 3D 修仙动画角色建模设定，写实而风格化的中国面孔，自然人体比例，精细皮肤、发丝、布料、金属与皮革材质；低饱和青黛、雾白、岩墨配色，克制电影级柔光，清晰轮廓，适合后续拆分为 2D 战斗角色。不要模仿任何现有动画、角色、服装或镜头。
构图：一张横向角色转面设定图，严格分成四个等宽竖向区域，从左到右依次为正面、左侧面、背面、右侧面；每个区域都是同一个角色、同一套服装、同一年龄和体型，完整全身、自然直立、双手放松、脚部完整可见、正交视图、无透视夸张。
背景：纯净暖灰白设计稿背景，无场景、无地面、无投影、无渐变。
约束：四个视图必须保持同一张脸、同一发型、同一服装结构、同一色彩；不要文字、标签、边框、额外人物、logo、水印、现代服装或夸张铠甲。
```

### 面部细节

```text
输入图像：图像 1 是该角色已确认的四视图锚点图。
用途：游戏角色制作资产，面部细节设定稿。
请求：仅基于图像 1 的同一角色，制作一张横向面部细节图，分成四个等宽区域：正脸中性表情、左侧脸中性表情、右侧 3/4 脸符合角色气质的轻微表情、眼睛与眉形及关键发饰/面部特征的局部特写。保留图像 1 的年龄、五官、发型、肤色、服装领口和饰品，不得重新设计角色。
画风：与图像 1 完全一致的原创高品质中国 3D 修仙动画角色建模设定，写实而风格化的五官，自然皮肤、发丝和细微材质细节；不要模仿任何现有动画的角色设计。
背景：纯净暖灰白设计稿背景，无场景、无投影、无文字。
约束：只出现同一角色；四个区域的脸必须一致；不要美颜滤镜、现代妆容、身体全景、logo 或水印。
```

## 登记与版本规则

- ID 永不复用；废弃资产保留 ID 和原因。
- 工作名可变，ID 不变，例如 `NPC-WYY-001`。
- 文件名采用：`<ID>_<asset>_v<版本>_<日期>`，例如 `NPC-WYY-001_turnaround_v01_20260801.png`。
- 每张 NPC 卡必须链接到关系 NPC、所属宗门、地图、任务和副本卡。
- 卡片中的“秘密”字段仅供制作组使用，不能直接进入玩家图鉴或普通对话。
