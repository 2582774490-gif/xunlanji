# 归墟雾港（炼气八层）

## 定位

归墟雾港是沿雾潮边境海路形成的自由港区。它负责把探索、资源航线和交易系统自然放到同一处，但不把它变成必须接取任务的中心。

## 区域尺度与美术组装

- 游戏逻辑区域为 `12000 × 8000`；目前接入的是第一个手绘石堤 / 泊位精细块。
- 港区不是单张背景图的边界。后续可在同一坐标空间继续增加外港、船坞、海蚀洞、拍卖后街、潮汐遗迹与外海航道块。
- 角色、武器、特效、NPC、资源与建筑交互必须保持独立运行时层，绝不烘焙进地表背景。

## 自由玩法

1. **归墟拍卖堂**：进入当前受价格范围和手续费保护的本地交易演示。真实玩家间寄售、竞价、结算与十人房间同步，等服务器接入后实现。
2. **潮路公告板**：只提供船期、流言与区域引导，不自动派发任务。
3. **沉船浅滩**：每次进入从潮砂、封蜡、航标片三类机缘中选择一类；可忽略。
4. **港区生态**：泊位行商只在码头活动，测潮散修只在公告区出现，沉桩水魇只守在危险的沉船浅滩。NPC 不能平均铺满区域。

## 境界与访问

- 炼气八层起可由雾潮边境的潮路进入。
- 这是区域强度与探索节奏门槛，并非任务链门槛；玩家可以通过修炼、采集、商路、其他副本或宗门路线抵达。

## 当前可验证内容

- 物理入口、港区大地图预留、精细地形块流式加载。
- 拍卖堂到现有市集页面的跳转。
- 公告板与沉船两个彼此独立的可选互动。
- 港口专属动态生态候选与共享开放世界遭遇战。

## 第二块外港扩展

- 新增与石堤区衔接的外港、船坞与海蚀洞方向地形块；玩家向东行进时，流式系统会从第一块码头切换到这一块，而不是离开一个封闭小地图。
- 船坞附近可出现修舟散修；海蚀洞外的潮池可独立采集潮洞灵藻，洞口范围则是潮穴鳞獭的合理生态领地。
- 海蚀洞目前是一个自由采集与探索提示点，未来将继续向外海遗迹副本、航线和更多海岸区块扩展。
