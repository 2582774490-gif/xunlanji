# 十人房中的双人论剑会话

## 范围

一个开放世界房间最多容纳 10 人，但一次论剑会话严格只容纳两名房间内玩家：挑战者与被挑战者。会话不是客户端自行声明的状态，而是服务器房间状态的一部分。

## 当前协议

1. 客户端发送 `duel_challenge(targetId)`；服务器验证双方都在同一房间、不是自己、也没有待定或进行中的会话。
2. 服务器建立 `pending` 会话并广播 `duel_sessions`。
3. 被挑战者发送 `duel_response(duelId, accept)`；服务器验证其正是目标玩家。接受后状态变为 `active`，拒绝后删除会话。
4. 任意一方离开十人房，服务器立即销毁相关会话并重新广播。

## 仍未完成的边界

`active` 目前只代表可信配对，不代表在线伤害结算已完成。下一阶段必须让服务器接收输入帧、校验冷却和距离、生成伤害与胜负，再把权威快照发给两个参与者。背包、交易和大世界十人位置同步仍与论剑结算隔离。
