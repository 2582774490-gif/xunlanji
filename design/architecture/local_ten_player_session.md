# 本机十人同区会话原型

## 当前边界

首发目标是单分区最多十名玩家。为让 Godot 客户端摆脱“只存在本地”的原型状态，项目新增了一个零依赖 Node WebSocket 房间服务：`server/src/websocket-room-server.mjs`。

- 监听：`ws://127.0.0.1:8080`
- 房间：默认 `launch-1`，硬上限 10 人；第 11 人会收到 `room_full`。
- 服务端分配临时在线身份，维护在线名册、区域、位置与朝向。
- 服务端会限制异常坐标范围，客户端不再拥有其他玩家的位置状态。

## 仍未声称完成的部分

该服务是可运行的局域/本机联机原型，不是已经能上线的 MMORPG 后端：没有账号登录、持久化数据库、断线恢复、反作弊、TLS、跨服、真实货币或服务端战斗判定。交易和 PVP 结算在正式上线前必须迁移至服务器权威逻辑，不能继续依赖客户端本地背包。

## 运行

在项目根目录执行：

```powershell
cd server
npm test
npm start
```

随后 Godot 客户端可连接本机房间；线上部署时只替换地址和服务进程，不改变消息边界。
