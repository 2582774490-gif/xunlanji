# 寻岚记：运行时装备分层规范（首发原型）

## 目标

角色不是一整张固定贴图。大世界与副本中的玩家由多个可替换节点组合：身体动作、武器、法宝，随后才是时装、发型和特效。这样同一个人物模板可以换装备，而不会把武器或饰品画死在背景和人物底图中。

## 现已落地的层

| 层 | 当前素材 | 节点与行为 |
| --- | --- | --- |
| 身体 | 男女八方向待机/移动关键帧 | `Body`，负责碰撞、朝向、移动帧与攻击帧 |
| 武器 | 青篁炼气剑 | `WeaponPivot/WeaponSprite`，跟随手部、移动滞后、攻击挥动 |
| 武器 | 回云炼气伞 | `WeaponPivot/WeaponSprite`，位于肩上方、移动时随身转向、攻击时短暂展开守势 |
| 法宝 | 纳灵玉佩 | `ArtifactPivot/ArtifactSprite`，独立悬浮、轻微绕行、面向变化 |

## 约束

- 未完成专属素材的武器或法宝，保持“素材待制作”，不得偷偷套用青篁剑、回云伞或纳灵玉佩。
- 时装、发型必须按身体动作规范导出，而不是把一张立绘直接盖到角色身上。
- 角色脚点始终作为碰撞与 Y 排序的依据；武器、法宝只作为子节点表现。
- 纳灵玉佩目前是视觉与装备流程原型，不提前承诺尚未制作的主动技能或数值收益。
- 已完成专属运行时素材的武器可在大世界或论剑场按 `Q` 无冷却切换；切换会立即替换 `WeaponPivot`，而不会要求重新进图。
