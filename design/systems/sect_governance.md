# 宗门运行与身份系统

## 首发原则

- 玩家可自由加入、退出或更换宗门；散修始终是一条完整玩法路径。
- 加入任一宗门均从外门弟子开始，不能直接取得高位。
- 身份需要同时满足境界与贡献，不能只靠短时间刷一次资源提升。
- 宗门不会替玩家决定修炼路线；提供的是资源、指引、关系与风险。

## 已接入的本地原型

| 身份 | 境界门槛 | 累计贡献 |
| --- | --- | --- |
| 外门弟子 | 炼气一层 | 0 |
| 内门弟子 | 炼气六层 | 80 |
| 执事 | 筑基中期 | 320 |
| 长老 | 结丹中期 | 900 |
| 副宗主 | 元婴中期 | 2400 |

贡献来源为进献材料与完成副本；材料被真正消耗。当前可加入雾隐剑宗、云市会、百草谷。

## 退出与后果

- 雾隐剑宗：内门及以上离宗会留下通缉记录；未来会在山道、驻地与宗门控制区生成合理的巡守追查。
- 云市会：高位离会冻结会内契约信用；正常离会不直接形成通缉。
- 百草谷：正常离谷留下关系记录，但不形成通缉。

雾隐剑宗的通缉记录已会在其实际管辖的雾潮边境关道生成巡守，触发大世界手操遭遇；它不会平均刷到无关区域，也不会在未通缉时出现。

目前记录仅保存在本地角色档案中。真实玩家任职、追捕、赎罪、宗门财产、跨玩家权限与反作弊必须在服务器权威同步后上线。
