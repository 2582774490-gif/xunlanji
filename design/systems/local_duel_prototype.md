# 云岚试剑台：本地 1v1 手操原型

## 已实现

- 可从“论剑”页进入实际 2D 场景，而非只停留在文字战斗面板。
- 玩家沿用大世界的方向移动、右侧攻击键与 `J` 攻击。
- 右侧五技能与 PVE 共用同一套首发技能数据：普攻、凝息剑诀、云步、岚息护体、润灵诀；键盘对应 `J` 与 `1–5`。
- 技能具备灵力消耗、独立冷却、远程伤害、位移、下一击减伤和回灵效果；未为其他武器偷套剑系专属贴图，当前只用中性的施法环提示。
- 试剑使会接近、保持交战距离并进行简单反击。
- 当前装备的武器档案会影响玩家承受的反击伤害；例如回云练气伞的防御减伤在此实际生效。
- 胜负仅本地记录为一次探索/试剑事件，不掉落装备，不计算排名。

## 明确边界

这不是网络 PVP。正式两人 PVP 仍需房间匹配、客户端状态同步、断线恢复、服务端权威命中与结算、反作弊、战绩系统。当前场景的价值是先验证移动、攻击、距离判定、武器表现与胜负状态能够在同一套 2D 世界逻辑中运行。
