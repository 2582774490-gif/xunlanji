# 《寻岚记》首发功法、法宝与装备生产清单

> 本清单是《首发功法、法宝与装备总录》的生产版索引。名称、来源、境界和玩法定位先冻结；只有完成独立原图、透明抠图、图鉴卡、运行时挂接和验证的条目，才可标为“可用”。任何条目不得借用其他武器或法宝的贴图、攻击动作或特效。

## 交付标准

每一件可见道具必须有以下四种产物：

1. **单体源图**：Image 2 生成，正视 3/4 角，主体居中，背景为纯洋红 `#ff00ff`，无文字、无水印、无场景、无投影。
2. **透明运行图**：从源图抠出透明 PNG，保留边缘，不将洋红底直接放进游戏。
3. **图鉴卡**：使用透明运行图与游戏内统一框体组合；信息由游戏 UI 绘制，不要求 AI 生成中文文字。
4. **玩法挂接**：武器至少有独立持握姿态、普攻效果和一个主技能；法宝至少有独立悬浮层和一次明确的触发反馈；防具至少有独立身体层和可验证数值。

统一禁止项：不使用任何现有动漫、小说或游戏的角色、道具、标识、画面；不在提示词中要求复制特定作品。美术目标是原创的精致中国仙侠动画感，以清晰轮廓、华贵材质、可读的战斗姿态为优先。
